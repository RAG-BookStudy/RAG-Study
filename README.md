## 📅 일정 및 장소

- **스터디 기간**: 2025.12.10(수, OT) ~ 2026.02.25(수) 예상 (총 11주)
- **모임 시간**: 매주 수요일 오후 8시 (1~2H)
- **모임 장소**: 온라인 (마법사관학교 디스코드 채널)

## 💫 진행 방식

1. 해당 주차의 지정된 챕터 학습
2. 개인 마크다운 파일에 학습 내용 정리
   - 학습 내용 요약
   - 인상 깊은 부분 / 새로운 개념
   - 실습 코드
3. **GitHub Pull Request**로 정리 및 코드 공유
4. 주간 모임에서 발표 및 토의
